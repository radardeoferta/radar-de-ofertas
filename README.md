# Radar de Ofertas

Achadinhos com cara de loja cara ✨

- `radar.py`: posta ofertas no Telegram (@oradardeoferta) e gera a vitrine
- `carrossel.py`: gera os carrosséis das séries, a agenda e baixa as fotos dos produtos (`imagens.txt`)
- `series.txt`: posts e séries da semana
- Site: https://radardeoferta.github.io/radar-de-ofertas
